Railway Linux Desktop - Huong dan

Su dung Desktop

Desktop XFCE chay trong khung noVNC ben phai. Di chuot, ban phim hoat dong nhu PC that. Thanh dock o duoi chua menu ung dung va cac launcher.

Mo Terminal

Cach 1: nut Terminal o sidebar. Cach 2: menu Applications > Terminal Emulator.

xfce4-terminal

Mo VS Code

Bam nut VS Code o sidebar. Lan dau se mat vai giay de khoi dong code-server, sau do mo tab moi tai dia chi /code/.

Mo Browser

Bam Firefox hoac Chromium o sidebar (ung dung mo ngay tren desktop). Hoac mo tu menu Applications.

Upload file vao Desktop

Dung trinh duyet ben trong desktop de tai file ve thu muc ~/Downloads, hoac dung Google Drive:

rclone config # cau hinh lan dau (chay drive-setup) drive-pull # tai file tu Google Drive ve Desktop/Documents/Downloads

Download file ra ngoai

drive-push # day Desktop/Documents/Downloads len Google Drive backup-data # tao ban backup .tar.gz trong ~/.backups

Luu du lieu

Luu tat ca vao /home/user. Neu gan Railway Volume tai /home thi du lieu ton tai qua cac lan redeploy. Chay backup-data dinh ky de an toan hon.

apt install

sudo apt update && sudo apt install -y ten-package

Cai tu file .deb

wget https://example.com/app.deb sudo dpkg -i app.deb sudo apt-get install -f # sua dependency neu can

AppImage

chmod +x app.AppImage ./app.AppImage

Python / pip

python3 --version pip3 install --user ten-thu-vien

Node.js / npm

node --version npm install -g ten-package

Git va CLI tools

git --version sudo apt install -y htop jq ripgrep

Git / GitHub

git clone https://github.com/user/repo.git ~/Projects/repo cd ~/Projects/repo git config --global user.name "Your Name" git config --global user.email "you@example.com"

Push len GitHub dung Personal Access Token khi duoc hoi mat khau.

npm / Python chay du an

cd ~/Projects/myapp && npm install && npm start cd ~/Projects/myapp && pip3 install -r requirements.txt && python3 main.py

code-server

VS Code web tai /code/. Mo bang nut VS Code tren sidebar. Thu muc mac dinh la /home/user.

SSH client

ssh-keygen -t ed25519 ssh user@host
Container chua SSH client. Muon SSH DEN container tu ngoai can them TCP proxy rieng tren Railway (khong bao gom san).

Cau truc thu muc

/home/user/Desktop # desktop icons /home/user/Documents # tai lieu /home/user/Downloads # tai xuong /home/user/Projects # source code dat o day /home/user/.backups # backup tu dong /home/user/Drive # Google Drive mount (neu da setup)

Railway Volume

Tren Railway dashboard: Service > Volumes > gan volume tai duong dan /home. Sau khi redeploy, du lieu van con nguyen.

Backup / Restore

backup-data # tao backup vao ~/.backups (tu dong gioi han 5 ban) restore-data # phuc hoi tu ban backup moi nhat

Optimize System

Bam nut Toi uu o sidebar. He thong se quet CPU/RAM/disk, don dep apt cache, file temp, cache trinh duyet, thumbnails va toi uu XFCE. Du lieu nguoi dung (Documents, Projects, SSH keys...) KHONG BAO GIO bi xoa.

Giam RAM

Dat bien moi truong: RESOLUTION=1366x768, VNC_DEPTH=16, VNC_FPS=24. Dong ung dung nang (Chromium/GIMP) khi khong dung. Chay Optimize System dinh ky.

Giam CPU

Watchdog tu dong renice tien trinh nang. Tat hieu ung: compositor da tat san. Han che so tab Chromium.

Disk

df -h / du -sh ~/* | sort -h optimize-system --dry-run # xem truoc se xoa gi

Hoi mat khau VNC khi ket noi

Mat khau mac dinh la railwaylinux. noVNC se hoi mot lan moi phien. Doi mat khau bang bien moi truong VNC_PASSWORD tren Railway. Tat xac thuc: dat VNC_PASSWORD=none.

Connecting... / Failed to connect

1. Container moi boot: cho 15-30 giay, trang thai se tu chuyen sang Connected.
2. Bam nut Reconnect o sidebar hoac tren man hinh loi.
3. Kiem tra /health neu van loi lau hon 2 phut.
4. Cuoi cung: Railway > Deployments > Restart.

Desktop den / khong hien

Xem Logs > xfce. Watchdog tu khoi dong lai XFCE trong vong 30 giay. Neu treo lau: bam Reconnect.

Browser khong chay video

chromium --no-sandbox https://youtube.com

Codecs da cai san. Neu Van loi, thu Firefox ESR.

VS Code khong mo

Bam lai nut VS Code (he thong se kiem tra port va khoi dong lai code-server). Xem Logs > code-server neu van loi.

Container restart

Khi Railway restart container, toan bo desktop boot lai tu dau trong ~20-40 giay. Du lieu tren Volume giu nguyen. Backup tu dong chay khi tat.

PORT

Railway tu gan bien PORT. HTTP server luon listen 0.0.0.0:$PORT. Khong can cau hinh gi them.

Volume

Service > Volumes > Mount path: /home. Kich thuoc tuy chon (1GB+).

Variables

PORT=8080 # tu dong boi Railway RESOLUTION=1600x900 VNC_DEPTH=24 VNC_FPS=30 IDLE_TIMEOUT=0 # 0 = chay 24/7, khong sleep ENABLE_PROXY=0 # 1 = bat Tor ENABLE_AUDIO=0 MEM_LIMIT_MB=1228

Domain

Settings > Networking > Generate Domain. Web desktop chay ngay tai domain do.

Logs / Restart / Redeploy

Tab Deployments xem log boot ([BOOT], [VNC], [XFCE] tags). Nut Restart de khoi dong lai container. Redeploy khi cap nhat repo.

System Optimizer
Canh bao: tien trinh se don dep apt cache, file tam thoi, log cu, cache trinh duyet va thumbnails. Du lieu nguoi dung (Desktop, Documents, Downloads, Projects, SSH keys, cau hinh) KHONG BI ANH HUONG. Khuyen khich dong cac ung dung nang truoc khi chay. Qua trinh mat khoang 10-60 giay.
